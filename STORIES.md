#  📖 Läslistan

## User Strories

### Base page

Som användare   
vill jag tydligt se sidans huvudrubrik  
så att jag vet att jag är på rätt sida

acceptanskriterium: Huvudrubriken ska finnas och innehålla den förväntade texten.


Som en användare  
vill jag mötas av en välkomsthälsning på startsidan  
så att startsidan känns välkomnande  

acceptanskriterium: En text "Välkommen!" ska visas på sidan

Som en användare  
vill jag se sidans knappar för navigation  
så att jag vet vad jag kan göra på sidan  

acceptanskriterium: Knapparna "Katalog", "Lägg till bok", "Favoriter" och "Statistik" ska visas på sidan


### Catalog view

Som en användare  
vill jag kunna öppna vyn katalog och se dess rubrik  
så att jag vet att jag navigerat rätt och kan utforska böckerna

acceptanskriterium: Sidbeskrivning som innehåller texten "Sidan för dig som gillar att läsa"


Som en användare  
vill jag förvissa mig om att det finns böcker i katalogen  
så att jag vet att listan inte är tom  

acceptanskriterium: Det finns minst en bok listad i katalogen


som en användare  
vill jag kunna se alla böcker i katalogen  
så att jag kan utforska vilka böcker som finns tillgängliga  

acceptanskriterium: Alla böcker som ingår i katalogen ska visas.


Som en användare  
vill jag kunna markera en bok som favorit  
så att jag kan markera de böcker jag tycker om  

acceptanskriterium: Det ska gå att favoritmarkera en bok


Som en användare  
vill jag kunna ta bort en bok från mina favoriter  
så att jag kan ändra vilka böcker jag tycker om  

acceptanskriterium: Det ska gå att ta bort en favoritmarkerad bok


### Add book view

Som en användare  
vill jag kunna klicka på knappen "Lägg till bok"  
så att jag kommer till vyn för att lägga till en bok  

acceptanskriterium: När användaren klickar på knappen "Lägg till bok" ska formuläret för att lägga till en bok visas


Som en användare
vill jag kunna aktivera knappen ”Lägg till ny bok” när jag fyllt i formuläret
så att jag kan lägga till boken.

acceptanskriterium: När användaren har fyllt i både titel och författare ska knappen ”Lägg till ny bok” aktiveras.



Som en användare  
vill jag kunna lägga till en ny bok  
så att jag kan se den i katalogen  

acceptanskriterium: När användaren lagt till en ny bok ska den listas i katalogen
