#  📖 Läslistan

## User Strories

### Läslistan base sida

Som användare   
vill jag tydligt se sidans huvudrubrik  
så att jag vet att jag är på rätt sida

acceptanskriterium: Huvudrubriken ska finnas och innehålla den förväntade texten.


Som en användare  
vill jag mötas av en välkomsthälsning på startsidan  
så att startsidan känns välkomnande  

acceptanskriterium: En text "Välkommen!" ska visas på sidan

Som en användare  
vill jag se sidans knappar för navigation  
så att jag vet vad jag kan göra på sidan  

acceptanskriterium: Knapparna "Katalog", "Lägg till bok", "Favoriter" och "Statistik" ska visas på sidan


### Katalog Vyn

Som en användare  
vill jag kunna öppna vyn katalog och se dess rubrik  
så att jag vet att jag navigerat rätt och kan utforska böckerna

acceptanskriterium: Sidbeskrivning som innehåller texten "Sidan för dig som gillar att läsa"


Som en användare  
vill jag förvissa mig om att det finns böcker i katalogen  
så att jag vet att listan inte är tom  

acceptanskriterium: Det finns minst en bok listad i katalogen


som en användare  
vill jag kunna se alla böcker i katalogen  
så att jag kan utforska vilka böcker som finns tillgängliga  

acceptanskriterium: Alla böcker som ingår i katalogen ska visas.


Som en användare  
vill jag kunna markera en bok som favorit  
så att jag kan markera de böcker jag tycker om  

acceptanskriterium: Det ska gå att favoritmarkera en bok


Som en användare  
vill jag kunna ta bort en bok från mina favoriter  
så att jag kan ändra vilka böcker jag tycker om  

acceptanskriterium: Det ska gå att ta bort en favoritmarkerad bok


### Lägg till bok Vyn

Som en användare  
vill jag kunna klicka på knappen "Lägg till bok"  
så att jag kommer till vyn för att lägga till en bok  

acceptanskriterium: När användaren klickar på knappen "Lägg till bok" ska formuläret för att lägga till en bok visas


Som en användare
vill jag kunna aktivera knappen ”Lägg till ny bok” när jag fyllt i formuläret
så att jag kan lägga till boken.

acceptanskriterium: När användaren har fyllt i både titel och författare ska knappen ”Lägg till ny bok” aktiveras.


Som en användare  
vill jag kunna lägga till en ny bok  
så att jag kan se den i katalogen  

acceptanskriterium: När användaren lagt till en ny bok ska den listas i katalogen


### Mina böcker Vyn

Som en användare  
vill jag kunna klicka på knappen "Mina böcker"  
så att jag kommer till vyn för mina böcker 

acceptanskriterium: När användaren klickar på knappen "Mina böcker" ska vyn för favoritböcker visas


Som en användare  
vill jag få information när min favoritlista är tom 
så att jag förstår varför inga böcker visas

acceptanskriterium: När listan med favoriter är tom ska meddelandet "När du valt, kommer dina favoritböcker att visas här." visas


Som en användare  
vill jag kunna lägga till en bok som favorit 
så att jag kan se den i listan av mina favoriter

acceptanskriterium: När användaren lagt till en ny favoritbok ska den finnas med i favoritlistan


Som en användare  
vill jag kunna ta bort en bok från favoritlistan 
så att jag kan uppdatera mina favoriter

acceptanskriterium: När användaren tar bort en bok från favoriter ska den tas bort från favoritlistan


### Statistik Vyn


Som en användare  
vill jag kunna klicka på knappen "Statistik"  
så att jag kommer till vyn för statistik 

acceptanskriterium: När användaren klickar på knappen "Statistik" ska vyn för statistik visas


Som en användare  
vill jag kunna se hur många böcker som finns i katalogen  
så att jag vet hur många böcker som finns just nu  

acceptanskriterium: När användaren går till vyn statistik ska antal böcker i katalogen visas


Som en användare  
vill jag kunna se hur många böcker som har hjärtmarkerats av användarna   
så att jag kan se hur många favoritmarkeringar som finns  

Acceptanskriterium: När användaren går till Statistikvyn ska antalet favoritmarkerade böcker visas.


Som användare  
vill jag att statistiksidan visar samma antal böcker som katalogen innehåller  
så att jag vet att statistiken alltid är korrekt när jag lägger till en bok  

acceptanskriterium: När en bok läggs till ska katalogen och statistiken visa samma antal böcker


Som en användare   
vill jag att statistiksidan visar samma antal hjärtmarkerade böcker som Mina böcker innehåller  
så att jag vet att statistiken för favoritböcker alltid är korrekt  

acceptanskriterium: När användaren ändrar favoritmarkeringen av en bok ska antalet i Mina böcker och statistiken vara samma
